# DSH Tavern v2.6 变更记录

从 **v2.5 到 v2.6 共 281 个提交**，其中 64 个是自动生成的运行时清单提交。统计范围为 `v2.5..bd7fd853`，详见[完整提交清单](v2.6-commits.md)。

**这一版重点：插画功能大幅增强，改人物卡更省 token，长存档更流畅，插件可以接入游玩的更多环节。**

插画方面：同一轮正文可以新增多张插图，并可附一句想画的场景；可以自己写提示词重画；新增画廊；较早的轮次也能补画；画风默认由 AI 按题材自动确定并保持连续。改人物卡方面：实测一次改卡的 token 消耗减少约七成。长存档的写入、回退、重新生成和翻看旧楼层，不再随存档变大而变慢。新增存档导出与导入。插件接口扩展到结算、候选、压缩、世界书条目和界面面板。

## 场景插画

**新增插图与提示词**

- 同一轮正文可以「新增插图」，最多 6 张：可以写一句想画的场景，也可以留空，由 AI 另选一个与已有插图不同的时刻。每张插图插在各自对应的那句话之后，可以分别重画、改提示词和删除（#195）。
- 插图下直接提供「改提示词」：自己写的提示词原样发给生图渠道，中文、英文或标签都可以，不经过文字模型；画风设置仍会追加在后面。
- 重画分为「重新构思画面」和「同方案重画」，也可以先写修改意见再重画。大图可以展开「画面方案」，查看这张图的构思、画风和提示词。

**画面与画风**

- 画面选择动作正在发生的那一刻，构图按电影分镜来写；插图显示在所画那一幕的段落之后，不再一律放在本轮末尾。
- 新增默认的「自动」画风：AI 按卡片题材定下画风，之后的插图参考最近一张，保持连续。也可以「锁定画风」，写自己的画风描述。
- 同一人物在整局只用一个编号，补画较早的轮次也不会另起编号；新登记的人物直接用名字作编号。
- 生图 Agent 默认沿用对话模型、用最低推理强度，不会在整理画面前长时间思考；也可以在全局默认和本局设置里单独选择模型。

**入口与管理**

- 生图、重试和重新生图都放在每轮操作栏的图标里；较早的轮次也能补画，失败后可以在插图位置重试。
- 新增「画廊」标签页：按轮次排列本局全部插图，大图可以左右翻页，支持逐张删除和批量删除。
- 文生图对话页可以撤销最近一轮对话。
- 生成中显示占位框、当前阶段和用时；插图的删除、重画等按钮在鼠标移上去时显示，触屏设备上始终显示。

**设置与渠道**

- 场景生图配置移到单独的设置页，新增「测试生图」：按已保存的配置出一张测试图。全局开关「开启场景生图」默认关闭，保存完整配置后才能打开。
- 读取模型列表后可以从下拉列表里选择。NovelAI 接入点可以选官方格式或对话格式；渠道收到网页、或 Images 接口返回 404 时，会提示改用合适的渠道。
- 软件和文档不再提及具体的第三方服务，统一称为「自定义渠道」「兼容接口」。

## 改人物卡更省 token

- 卡片工作台每一步都要把全部上下文重发一遍。大卡的常驻世界书（可达 8–9 万字）、超长的人物设定和系统提示不再整段预载，超过 8000 字时改为提示 Agent 按需读取。
- 新增两个工具：「全卡搜索」一次搜遍字段、开场、世界书标题／关键词／正文、正则和脚本；「全卡替换」一次完成定位、替换、保存和校验，并报告每处改动和全卡剩余处数。Agent 不再反复写脚本翻 JSON、反复核对。
- 保存人物卡或内置世界书时，结果里自动附带格式校验，省掉单独校验的一步。
- 只有加载了对应 Skill，才会出现 Cordis、保存 Skill、长期偏好、读游玩记录等任务专用工具；新旧两套文件编辑工具同时存在时，只保留新版。读世界书只返回正文原文和设置过的字段。
- 实测：大卡上改一处的任务，平均从约 19 万 token 降到约 4 万；全卡 10 处改名，从约 16 万降到约 4.5 万。
- 卡片 Agent 创作或修改的人物卡，在创作者备注里以 Co-authored-by 格式署名 DSH Tavern。

## 长存档性能

- 正文提交、世界书召回、变量结算、编辑正文、回退、撤销回退和重新生成，都只读写最近相关的楼层，不再整档读取或重写。
- 浏览旧楼层时按页扩展历史，不再切换到完整历史；较远的楼层换成同高的占位，卡片按实测高度占位，阅读位置保持不动。
- 卡片 iframe 只内联近期楼层；切换会话只下载一次完整视图。
- 世界书筛选改在回复结束后预筛，发送消息时不再等待；只在候选超过 5 条、且超过约 3000 tokens 时才触发；被排除的条目冷却 10 轮。
- 后台共享会话的各项任务使用相同的系统指令和工具列表，变量结算把不变的结构和规则放在前面，更容易命中前缀缓存。

## 存档与导出

- 新增导出存档：一个文件包含回退历史、原生会话、人物卡、配图和插件数据；导入后作为一局新游戏继续玩。
- 「导入存档」改为菜单，区分 DSH Tavern 存档和 SillyTavern 聊天记录。
- 删除游戏时，一并清理这局的日志、诊断、生图记录、原生会话和后台会话。
- 「故事正文」改为 Markdown 导出：配图以相对链接插在对应段落之后，每轮新增的插图也一起导出。

## 游玩体验

- 候选面板精简：点选候选即追加到输入框，再点一次取消；可以连续点选多项，发送后才收起。
- 重新生成正文时，自动填入本局上次用过的指导意见。
- 重做剧本进度面板。
- 手动整理游玩台账后，下一轮正文会参考一次台账。
- 本局设计的人物会在下一轮正文里注入一次，之后按关键词召回；人物设计档案可以逐条删除。
- 新增正则库：导入原版酒馆正则，存放在库里不直接生效，由卡片 Agent 写入人物卡或预设。
- Skill 库支持导入 SKILL.md 或 Skill 文件夹压缩包。Guide 库可以删除整个方案。
- 上下文压缩可以设置「压缩后保留最近几轮原文」（0–100，默认 10）；摘要请求只返回工具调用时，改用纯文本请求重试一次。
- 侧栏对话按开始时间排序，人物卡分组按最近活动排序；人物卡列表按近期导入和游戏局数排序，批量管理改为单行工具栏。
- 设置：默认隐藏上下文注入和思考过程，默认模型各行补充用途说明，隐藏插件、Agent 预设和侧边卡片设置页。
- 手机导入下载目录时显示缩略图，支持多选、排序和筛选；手机竖屏的侧栏收进抽屉，正文全宽（dsh-web-mobile 2.4.1）。

## 插件接口

- 开放宿主侧 `tavern` 服务和浏览器侧 `tavernUi` 服务：轮次通知；读正文、设定和变量；挂载媒体；正文提示词段落；消息与输入框按钮；本局插件面板；开始页分组；静态资源。
- 开放层覆盖更多游玩阶段：结算、候选、压缩的添加类接口，替换结算（可被玩家停止），自定义结算任务与手动任务，插件条目进入世界书条目池，由 Tavern 统一召回、冷却和筛选。
- 插件存档数据绑定正文版本，回退和分叉时自动跟随；导出存档包含插件数据。插件建的子 Agent 记入该局的请求记录。
- 插件放进数据目录的 `plugins/` 文件夹即可加载，运行中增删无需重启；插件加载出错只记日志，不影响 DSH 启动。
- 上线插件开发文档网站（接口参考和常见用法），内置 tavern-plugin Skill 和示例插件。

## 修复

- 失败回合的输入不再混进下一轮（#193）。增量视图重新计算最新轮次，插件按钮不再挂到旧轮次（#189）。任务表被存成数组时自动修正，新任务不再静默丢失（#178）。
- 预设：游玩中修改本局预设，下一次请求立即生效；停止把新对话迁移到已退役的方案，并恢复被误迁移的对话（#166）；预设中段、后段的 random/roll 按每轮种子展开。
- 回退、重新生成与分叉：用户气泡按原生轮次取输入，不再错位；上一轮变量变化的提示不再被当成本轮输入；分叉不再误报「正文仍在生成」，也不会把分叉后的新回复整轮隐藏；整段回退失败时改用新的后台会话（#164）。
- 编辑正文时保留原有的首尾空行，卡片结构块不再黏在正文末尾。预设中「只发给模型」的输入正则不再写进保存的玩家消息。
- MVU：开场 `<initvar>` 能生成变量结构，并清理 `$meta`；后台结算不再把 `$meta` 当成状态字段。
- 卡片 iframe 的配色跟随 DSH 主题，深色主题下不再显示白块；切换对话时关闭上一局的状态栏 iframe；所有卡片的鼠标跟随 3D 倾斜特效一律还原。
- 子 Agent 会话不再被注入酒馆回合上下文；本轮世界书上下文去掉多余的标题和说明，未触发条目的轮次不再注入；后台任务消息更精简。
- 局部刷新时补算剧本进度、游玩台账和人物设计，后台任务完成后面板无需重启就能更新。

## 安装与更新

- Windows：界面更新切换目录时，不再因工作目录被占用而报 EBUSY，失败摘要显示真实错误；启动器结束旧酒馆进程被拒绝时，不再中断安装（#192）。新的安装包为 Setup8。
- 依赖补丁补上 `diff --git` 标头，pnpm 12 不再报 ERR_PNPM_INVALID_PATCH（#194）。
- 诊断包记录会话补丁状态；补丁未能安装时，启动日志会打印原因。
- 正式版本同时发布到 npm（`dsh-profile-tavern`），对外的安装方式不变。
- 使用文档按当前界面更新，手册截图全部重拍；「用户画像」统一改称「长期偏好」。
