# DSH Tavern v2.7 变更记录

从 **v2.6 到 v2.7 共 60 个提交**，其中 14 个是自动生成的运行时清单提交。统计范围为 `v2.6..0f70ca60`，详见[完整提交清单](v2.7-commits.md)。

**这一版重点：存档大幅瘦身，转 MVU 大幅省 token。**

存档方面：长局的存档不再随轮数无限增长，大卡实测 20 轮从约 135 MB 降到约 30 MB，600 轮的存档本体从 24 MB 降到 7 MB；已有存档继续游玩时也会自动整理。转 MVU 方面：模型只负责设计变量、规则和面板，格式装配交给程序，实测三张卡的总 token 消耗减少约七成。

## 存档瘦身

- 空闲时自动整理存档：只保留当前版本、最近 50 轮的回退与分叉历史、撤销回退和重新生成的恢复点，删掉不影响游玩和导出的旧版本。每局结算完成后，若存档较上次整理增长了 50 个版本，且没有任务在进行，就整理一次。
- 卡片状态栏等 iframe 每 15 秒上报一次的运行采集，不再写进存档历史（实测一局 383 个版本里有 351 个来自这里）。
- 模型请求原文只留最近 3 轮、每局 8 MB 以内；世界书召回明细只留最近 10 轮；生图用的世界书快照按条目去重，只留最近 50 轮。
- 存档块合并写成块包，小文件从数千个降到数百个（存档格式 2）。
- 更早的轮次不再显示分叉按钮；导出存档跳过已清理的早期版本。
- 实测：大卡（大型世界书加 300 个变量字段）20 轮，含重新生成与回退，存档从约 135 MB 降到 24–34 MB；600 轮的存档本体从 24.3 MB 降到 6.8 MB。在本机真实数据上，整个数据目录从 1.1 GB 降到 739 MB，300 局的当前存档与回退版本逐一核对一致。
- 注意：升级后的存档用新格式保存，旧版本酒馆打不开，会明确提示不支持。请不要退回旧版本。

## 转 MVU 更省 token

- 新增「MVU 概览」工具：一次列出人物卡的开场（含开头和结尾）、世界书、正则和脚本，并标出可能的旧状态栏协议。Agent 不必再用命令行翻卡片文件。
- 新增「写入 MVU」工具：Agent 给出变量、各开场的不同值、更新规则和面板，工具负责把变量初值和状态栏入口写进每个开场，建好更新规则条目和面板正则，开场正文不动。旧状态块、旧说明条目和旧正则可以在同一次保存里一并删掉。
- 面板可以自己写完整 HTML（保留原卡状态栏的风格），也可以只给分组和字段，生成标准面板；之后要细调某一部分，可以只传那一部分。
- 修改 V2/V3 人物卡的字段时，文件根上的兼容副本同步更新。此前根上一直是旧内容，Agent 读文件核对时会误以为没存上而反复重改。
- 实测（三张卡各跑两次）：总 token 从约 433 万降到约 117 万，步数从 30–40 步降到 13–19 步；产出的卡全部通过格式校验，原卡的状态栏风格照样保留。

## MVU 卡脚本

- 电脑上页面在前台时，照旧由页面执行卡脚本。页面切到后台、关掉，或在手机上游玩时，改由服务端在后台运行卡脚本，变量照常结算，不必一直开着页面。
- 服务端运行失败时自动退回页面执行：单局失败后 5 分钟内不再尝试，连续失败 3 次后本次运行不再启用。设置环境变量 `DSH_TAVERN_SERVER_SCRIPTS=0` 可以关闭。

## 游玩体验

- 场景生图新增「每轮自动生图」开关，默认关闭：打开后每轮正文结算完成，自动为最新一轮画一张。已有插图、删过插图、生成失败或结果未确认的轮次不会自动重画，不会重复扣费（#195）。
- 重做「重新生成候选项」和「重新生成正文」面板：示例改为可点选的标签，支持 ⌘/Ctrl+Enter 提交、Esc 取消。候选和重新生成面板比输入框两侧各收进 12px。

## 插件接口

- 新增 `getCardImage`：读取这局人物卡的图片地址。

## 修复

- 存档漏记一轮后，重新生成、回退和编辑正文无法使用：现在自动补记，打开存档时先核对一次（#196）。新增存档与模型上下文的对账，能证明的不一致自动修复，其余记在日志。
- 上一轮输入被模板改写后，同步的消息不再被当成新一轮的玩家输入（#196）。卡片脚本等插件写入的消息不再被当成本轮输入，回退不再因此失效。
- 卡住的重新生成标记，不再因为一次被拒绝的发送或应用人物卡而永远无法恢复。旧正文与重新生成之间夹着别处写入的消息时，保留这条消息并完成替换，不再一直报「归属不一致」。
- 变量重试推进版本后，延后的重新结算不再一直停在「等待中」。
- 生图请求体上限由 16 KB 放宽到 256 KB，长提示词和批量删除不再失败。
- 更新不再删除用户自己安装的布局插件（如 CLI 上自装的 Pocket）。

## 安装与更新

- Windows 安装包与 v2.6 相同，仍为 Setup8；已安装的用户在应用内检查更新即可。
