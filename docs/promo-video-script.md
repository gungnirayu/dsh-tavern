# dsh-tavern 宣传视频文案

> 初稿。面向已有酒馆使用经验的玩家，以游玩痛点为主线。

玩酒馆最烦的，往往不是故事不好看，而是玩着玩着，总有些事让你出戏。

看完一大段正文，不知道下一句该接什么。  
状态栏突然掉了格式，数值和界面乱成一团。  
想好好玩个故事，却先折腾半天预设和配置。  
等了很久才生成一轮，读起来又满是熟悉的 AI 腔。

我做了一个 dsh-tavern，就是想让这些麻烦少一点。

## 不知道下一步该怎么走

dsh-tavern 自带行动候选。每轮正文结束后，会给你几种接下来的行动方向。

有喜欢的，直接选；想调整，改一下再发；有自己的想法，也可以自由输入。

如果你希望故事有一条明确的主线，还可以绑定小说、剧本或者大纲，跟着剧本往下玩。你有剧情可以跟，也随时可以做出自己的选择。

## 状态栏掉格式

很多人物卡让模型一边写故事，一边维护复杂的状态栏。玩着玩着，格式就可能乱掉。

在 dsh-tavern 里，你可以让卡片 Agent 帮你把人物卡转成 MVU 卡。转换后，状态由后台 Agent 更新，状态栏固定显示在右侧。

正文生成不再负责重复拼出整个状态栏，也就避免了正文漏写、写坏状态栏格式的问题。

## 还没开始玩，就被配置劝退

这里默认使用内置预设。完成安装和模型配置后，导入人物卡，就能开始游玩，不用先四处找预设、反复调参数。

想深入折腾也可以，世界书、预设和系统提示词都有调整入口。

## 人物卡有些地方不满意

性格不合心意，背景想补充，开场想换一种写法——直接进入卡片模式，把想法告诉 Agent。

它会和你讨论修改方案，确认后帮你改好。你负责说清楚想怎么玩，具体的资源修改交给它处理。

## 故事玩长了，前面的事情被忘掉

刚做过的约定，过几轮就不认了；重要的人物关系，聊着聊着又变回原样。

dsh-tavern 自带记忆检索，让过去的剧情有机会在需要时被重新找回来，为后面的故事提供依据，减少长期游玩中的遗忘。

## 在酒馆里积累的资源，也能继续用起来

除了人物卡，dsh-tavern 还支持世界书、预设、正则美化和 MVU，并适配部分小手机等扩展玩法。

熟悉的人物，熟悉的美化效果，可以带到这里，体验新的游玩方式。

## 每一轮都要等很久

dsh-tavern 把正文、候选项和后台状态处理拆开，按需提供上下文，减少重复输入和不必要的 Token 消耗。

目的很直接：少一点等待，少一点消耗，让你能顺着刚才的情绪继续玩。

## 文本里的 AI 味太重

前后台分离，也让前台模型可以更专注于文字本身，减少格式任务对叙事的干扰。再配合剧本文字引导，改善那些反复出现的套路和 AI 腔。

## 电脑上能玩，手机上也可以接着探索

支持 Windows、macOS 和 Linux，Android 仅提供独立 APK（Android 11+ / ARM64）。

## 结尾

如果你也喜欢酒馆，却经常被这些问题打断，可以试试 dsh-tavern。

导入一张喜欢的人物卡，从下一步怎么走开始。
